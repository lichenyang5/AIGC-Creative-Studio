# AIGC Creative Studio：面试演示与本地初始化清单

> 这份清单用于新电脑初始化、现场面试演示与自测。它不包含真实 API Key、用户密码或图片数据。

## 一、首次初始化

### 1. 安装依赖

在项目根目录执行：

```powershell
npm ci
Set-Location server
npm ci
```

### 2. 准备 PostgreSQL

可以使用本机 PostgreSQL 16/17，也可以启动仓库提供的 Docker PostgreSQL：

```powershell
Set-Location <项目根目录>
docker compose up -d postgres
```

复制环境变量模板，但不要提交生成的 `.env` 文件：

```powershell
Copy-Item .\.env.example .\.env
Copy-Item .\server\.env.example .\server\.env
```

至少确认 `server/.env` 中的 `DATABASE_URL` 和 `JWT_SECRET` 已填写。需要真实生图时再填写 `DASHSCOPE_API_KEY` 并将 `ENABLE_REAL_GENERATION=true`；只演示账号、图库、编辑器和数据库时可以保持 `false`。

### 3. 一条命令初始化或升级表结构

```powershell
Set-Location server
npm run db:setup
```

该命令读取本机 `server/.env`，执行 `server/sql/schema.sql` 中可重复运行的建表和索引语句。它不会清空已有用户、任务、图片或活动日志。

确认数据库中存在以下表：

```text
users
generation_tasks
images
activity_logs
```

## 二、启动与质量检查

使用两个终端：

```powershell
# 终端一：后端
Set-Location <项目根目录>\server
npm run dev

# 终端二：前端
Set-Location <项目根目录>
npm run dev
```

提交或演示前建议运行：

```powershell

npm run lint

# server 目录
npm run build

```

## 三、5 分钟面试演示顺序

1. 注册两个测试账号，登录第一个账号。
2. 打开“图片创作”，填写 Prompt 并创建一条任务；说明 `POST /api/generations` 先返回本地 taskId，前端再轮询状态。
3. 打开“生成库”，说明任务和图片按 `user_id` 隔离；切换第二个账号后，第一账号资源不可访问。
4. 打开一张图片进入 Canvas 编辑器，演示灰度、灰度渐变、雨滴或色彩涟漪，并导出 PNG。
5. 将编辑 PNG 保存回生成库，说明原图和编辑作品的 `source_image_id` 关联。
6. 打开右上角用户名进入“个人中心”，展示任务统计和最近活动。
7. 使用 pgAdmin 展示表关系：`users → generation_tasks → images`，以及 `activity_logs.user_id`。

## 四、重点讲解的话术

### 为什么要把生成过程建模为任务

图片生成是长耗时外部调用。创建接口返回 `202` 和 taskId，后台执行 Provider 调用；任务状态由 `pending` 进入 `processing`，最后收敛为 `succeeded` 或 `failed`。服务重启时遗留的 `processing` 任务会安全标记失败，避免前端永久轮询。

### 为什么图片不直接使用 Provider URL

Provider 返回的 URL 可能过期，也不处于本项目权限体系中。后端会下载该 URL 对应二进制到 `server/storage/images`，再由鉴权接口根据当前用户权限返回本地图片。

### 为什么还要做操作日志

`activity_logs` 是独立的一对多记录，不污染任务主表。它只保存用户动作、关联任务和安全摘要，个人中心只查询当前用户最近 8 条，日志写入失败不会影响用户刚刚完成的生成、编辑或删除操作。

## 五、演示环境边界

- 本项目适合单机学习、作品集和全栈面试演示；
- 图片文件在本地磁盘，数据库只保存元数据；
- 浏览器导入素材和本地编辑作品在 IndexedDB，不会上传到服务端；
- 真实模型调用需要自行配置 DashScope Key；
- 生产环境仍应进一步引入独立 Worker、队列、对象存储、限流、审计告警和部署环境隔离。
